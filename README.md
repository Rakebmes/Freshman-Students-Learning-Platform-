# Freshman-Students-Learning-Platform-
It is a centralized web based learning platform that supports first year university students in their academic studies. The platform will provide organized access to shared freshman course materials, lecture notes, past examination papers, educational videos, and interactive quizzes. It will be developed using HTML, CSS, and JavaScript.
